# Portofolio Software Developer: Nakeya Canakia

Tugas 1 Pemrograman Web: Responsive Landing Page (Tema C, Portofolio Profesional Pengembang Perangkat Lunak).

## Fitur
- HTML5 semantik: header, nav, main, section, article, aside, footer
- Hierarki heading runtut (h1 > h2 > h3 > h4) dan aksesibilitas WCAG 2.1 (skip link, aria-label, alt deskriptif, label formulir)
- CSS modern tanpa framework: Flexbox (navigasi, tombol, tag) dan CSS Grid (kartu, layout bagian)
- Mobile-first dengan breakpoint `min-width: 768px` dan `min-width: 1024px`
- Tanpa horizontal overflow pada 320px sampai 1920px
